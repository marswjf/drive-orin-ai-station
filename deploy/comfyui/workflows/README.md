## 各张的关键参数

### 局部重绘

遮罩交给 `ZImageFunControlnet` 做局部约束，`DifferentialDiffusion` 负责边界过渡，
所以 **KSampler 的 denoise 是 1.0 也不会整张重画——这个 1.0 不要改小**，改小反而让重绘区糊。

- 用法：图片上右键 → 打开遮罩编辑器 → 涂抹要重画的区域 → 保存 → 写提示词 → 运行
- 预置示例图 `inpaint-768x1024.png` 中间自带一块 304×320 的遮罩，可直接跑一次看效果
- ControlNet：`Z-Image-Turbo-Fun-Controlnet-Union-2.1-lite-2602-8steps.safetensors`（1.88 GB，
  在 `/opt/m/sd-models/model_patches/`）
- 挂着一个官方 4 步蒸馏 LoRA，**默认旁路**。要启用就取消旁路并**把步数从 8 改成 4**

### 文生图 4K 极速版

- 出图 928×1648（10 步 / CFG 1.0）→ 4x-UltraSharp 超分 → 归一到 2160×3840
- 左侧「高清放大」开关可把超分整组旁路，直接出 928×1648 原图，快很多
- ⚠ **`ImageScaleToTotalPixels` 的 `megapixels` 是 1024 进制**（源码 `total = megapixels * 1024 * 1024`），
  不是一百万。按 8.3 填实测出 2216×3928，比 4K 长边大 2.3%；**7.92 才是正好 2160×3840**

### 老照片修复

唯一需要调的是 KSampler 的 `denoise`：

| 值 | 适用 |
|---|---|
| 0.25~0.32 | 划痕轻，只想去噪 |
| **0.40** | 默认 |
| 0.45~0.55 | 划痕重、缺角、发霉 |
| >0.6 | **人物长相会变**，修老照片没意义 |

三档实测耗时几乎相同（104.2 / 98.6 / 98.2 秒）——瓶颈在超分与 VAE 解码，不在采样。
超分模型可换：`4x-UltraSharp` 偏锐利，`RealESRGAN_x4plus` 偏自然。

⚠ **实测补充（2026-09-01）**：用合成测试图（832×464，两道纯白高对比长划痕）跑 0.40 档，
人物与泛黄质感都正常，**但那两道划痕没有被去掉**。低重绘保结构，代价就是高对比度的
长划痕会被当成画面结构保留下来。真遇到明显划痕，按上表调到 0.45~0.55。

## `上游原版/` —— 社区工作流，**按原样在这块板子上都跑不起来**

留档供参考结构与提示词，不是可用配置。共同障碍：

| 障碍 | 涉及 | 说明 |
|---|---|---|
| **bf16 全套装不下** | 全部 5 个 | 都引用 `z_image_turbo_bf16`（合计 19.3 GB），**【实测 2026-08-14】** 载入即被 OOM 杀。改用 `UnetLoaderGGUF` + Q8_0 可解 |
| **SeedVR2 超分** | 极速版、4K放大 | 7B fp16 约 14 GB 单独就超预算；3B 版是 **fp8，板上缺 dtype**。→ 换 `UpscaleModelLoader` + `ImageUpscaleWithModel`，已在文生图 4K 上落地 |
| **FLUX.2 / Qwen3-8B** | 老照片修复+全节点注释 | `flux-2-klein-9b` 18 GB、`qwen_3_8b` 编码器 16 GB，按 fp16 档都装不下。**【算术】** 不随环境过期，但**只算了 fp16**——要用这条排除一个模型之前，先查它有没有 GGUF 量化档 |
| 缺自定义节点 | 全部 | 合计 35 个，分属 easy-use / Impact / essentials / LayerStyle / TTP / ControlNet-Aux 等包 |
| ~~缺 ControlNet~~ | ~~4 个~~ | **已解决**：`Z-Image-Turbo-Fun-Controlnet-Union-2.1-lite` 与官方 4 步蒸馏 LoRA 都已下到板上 |

> ⚠ 这张表里「SeedVR2 装不下」「bf16 装不下」仍然成立，
> 但**「ControlNet 跑不动」那条已经作废**——A-138 是 py3.10 / torch 2.4.1 旧栈的结论，
> A-156 用新栈（torch 2.11 + Flash Attention）推翻了它，本轮 768×1024 实测 36.4 秒出图。
> 引用任何旧结论前先看它是哪一档、什么时候测的。

**想改造哪一个，先按这个顺序做**：

1. 把 `UNETLoader` 换成 `UnetLoaderGGUF`（`unet_name` 填 `z_image_turbo-Q8_0.gguf`）
2. 删掉 SeedVR2 那一段，换成 `UpscaleModelLoader` + `ImageUpscaleWithModel`
   （做法见 `adapt-rules/fix-20260901-文生图4K真放大.js`，含每条改动的理由）
3. 剩下的缺失节点逐个评估——**看它的 `requirements.txt`，带联网依赖的直接放弃**
   （详见 `../README.md` 第 10 节，一个 matplotlib 让启动多花 408 秒）
4. LoRA 可以配 GGUF 用（`LoraLoaderModelOnly` 已注册），体积小，值得装
