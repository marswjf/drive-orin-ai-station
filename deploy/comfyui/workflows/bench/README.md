## 复跑时必须守的四条，缺一条数据就不可比

1. **重启服务后第一张不算数**——首张含模型载入（实测 81.8 秒 vs 稳态 30.2 秒）。
   跑第二张起才是稳态。
2. **比耗时必须每次换种子**。同种子第二次是缓存命中：3 秒返回、**文件名与上次完全一样**，
   那是缓存读取速度不是生成速度。判据就是文件名。
3. **比画面必须固定种子**，否则比的是两张不同的图。
   → 2 和 3 要求相反，**别混在一次跑里**：先固定种子比画面，再换种子比耗时。
4. **起步内存要干净**。`--highvram` 下上一个任务的权重继续常驻，
   叠加会在载入阶段 10~20 秒被杀。判据：被杀发生在载入而非采样阶段。
   ⚠ **这条在视频侧更致命，代价差一个数量级**：2026-09-02 实测，
   243 帧（更长）成功而 158 帧失败，**唯一差别是起步内存 7.7 GB 干净 vs 12.0 GB 脏**。
   生图重跑损失 30 秒，长视频跑到 **8 分钟**才被杀。**别拿"上次跑通了"当依据，看起步内存。**

## 这组数据什么时候会失效

它们是在 **`--highvram --disable-smart-memory`**（legacy ModelPatcher 路径）下测的。
**改动启动参数就要整组复跑**，不能只跑一两个——
`res_multistep` 与 `euler` 的相对关系可能随内存管理策略变化。
